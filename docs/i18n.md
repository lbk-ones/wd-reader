# 中英文国际化

支持 `zh-CN` 和 `en`。首次启动读取系统浏览器语言，`en`、`en-US`、`en-GB` 等英文环境使用英文，其他语言默认使用简体中文。用户选择优先于系统语言，保存在 `Wd-language`。语言立即切换，无需刷新，且同步更新 HTML `lang` 和 Ant Design locale。

入口为书架的“应用设置 → 语言”和阅读界面的“阅读偏好 → 语言”。“清除阅读记录”保留语言设置；“清空所有缓存”清除语言偏好，下次启动重新按系统语言选择。

## 添加文案

- `frontend/src/i18n/core.js`：语言选择、存储和不依赖 React 的翻译函数。
- `frontend/src/i18n/index.jsx`：订阅语言变更、`useI18n()`、`t()` 和组件库 locale。
- `frontend/src/i18n/en.js`：英文界面词典，以中文源文案为键。
- `frontend/src/i18n/en-help.js`：英文离线帮助词典。
- `frontend/src/i18n/LanguageSelect.jsx`：共用语言选择控件。

组件调用 `useI18n()` 订阅变更，并用 `t('中文源文案')` 显示文字。动态文案使用完整句子和占位符，例如 `t('成功导入 {count} 份文件', {count: 3})`。同时为英文词典添加对应翻译，并保留相同占位符。缺少翻译时回退到中文源文案。

全局 `t()` 在调用时读取当前语言，让启动时注册的事件回调也使用最新语言。不要在模块初始化时提前翻译后长期保存文案。右键菜单使用固定 `id` 分发操作，显示文字通过 `label` 翻译，不能用翻译后的文字判断业务操作。

## 数据与原生界面

书名、章节名、正文、自定义标题和原有缓存键不参与翻译。章节解析生成的“正文”“同名”等属于保存和检索使用的章节名称，也保留原样。

Go 错误协议中的 `错误信息:` 前缀保持不变，前端仅在显示时翻译已知应用错误；系统、文件路径和外部转换服务返回的原始诊断保留，便于定位问题。原生文件选择框标题由前端传入；操作系统管理的按钮和其他原生控件遵循系统语言。

## 验证

- `cd frontend && npm test`：19 项测试，包含语言回退、即时切换、重启持久化、多窗口同步、受限存储、占位符、已知错误展示及清除阅读历史保留语言。
- `cd frontend && npm run build`：通过；保留已有 Ant Design 指令与包体积警告。
- `go test ./...`、`go vet ./...`：通过。
- `wails3 build VERSION=dev`：Windows amd64 生产构建通过，输出 `bin/wdreader.exe`。
- Wails server 模式浏览器实测：书架切换英文、刷新保留语言、英文离线帮助、书籍阅读、英文右键菜单打开目录，以及阅读偏好内切回中文均正常。
- 英文设置使用单列布局，为较长标签和章节导航文字保留空间。
