# 迷你阅读独立操作窗口

普通阅读继续使用窗口内右键菜单。迷你阅读的窗口高度只有 120px，正文右键会调用 `OpenMiniMenu`，创建或复用独立的 Wails 窗口，避免菜单被阅读窗口边界裁切。

## 行为

- 操作窗口默认 344 × 520，置顶、无系统边框，不占任务栏；采用纸色背景和三组双列按钮，提供全部原有操作及退出迷你模式。
- 使用阅读窗口所在屏幕的逻辑坐标和工作区定位，保留边缘距离，底部空间不足时向上弹出；工作区较小时缩小窗口并允许内容滚动。
- 失焦、Esc 或关闭按钮收起窗口，重复打开复用窗口并更新语言、书名和章节。
- 翻页和切章在迷你模式下直接执行；打开目录、设置、帮助、返回书架或切换标题栏前恢复正常窗口。
- 迷你菜单中的“标题开关”会明确显示并保存标题栏状态，不会反转恢复窗口后的状态；普通模式下仍保持切换语义。
- 打开菜单时暂停自动阅读，关闭后恢复原来的自动阅读设置。
- 老板键、隐藏或最小化主阅读器时同步收起菜单；移出隐藏开启时，关闭菜单后继续遵守鼠标位置对应的隐藏行为。
- 后端校验操作标识并一次性领取命令，防止重复点击发送两次操作。

## 实现

- `mini_menu.go`：窗口生命周期、工作区定位、显示上下文与命令转发。
- `frontend/src/components/MiniReaderMenu.jsx`：`?view=mini-menu` 页面；不挂载主阅读器，不重复加载书架或注册阅读事件。
- `frontend/src/components/readerMenu.js`：菜单分组、稳定操作标识与正常窗口恢复规则。
- `frontend/src/App.jsx`：接收操作事件、暂停自动阅读、执行现有阅读操作。

## 验证

- `go test ./...`、`go vet ./...` 通过；覆盖工作区边界、负坐标屏幕、小工作区、底部向上定位、未知操作和关闭状态。
- 前端 25 项测试通过；菜单测试覆盖全部操作、中英文文案、窗口恢复规则、快捷键暂停，以及不同历史标题状态下恢复标题栏的回归场景。
- Windows 原生测试验证 120px 迷你窗口打开独立菜单、完整显示十二项、切章保持迷你、阅读设置恢复正常窗口、复用窗口更新章节、中英文同步、Esc 与失焦关闭。
- 原生测试使用隔离书籍、WebView 数据和单实例标识；仅测试实例显示任务栏图标以便自动化工具识别。生产窗口继续隐藏任务栏图标。
- macOS/Linux 原生多窗口行为尚未在本机实测。
