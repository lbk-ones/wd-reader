# 独立章节检测

本模块只负责章节边界判断，不依赖书库、Wails 或前端状态。

## 整体调用流程

从文件导入到章节显示，正文与目录始终使用同一套物理行坐标。职责分为三层：

| 层次 | 入口与文件 | 主要职责 |
| --- | --- | --- |
| 格式适配 | `source.ReadEPUB`、`source.ReadMOBIHTML`、`source.ReadHTMLSections` | 提取正文，解析原生目录，将文件与片段位置映射为物理行号 |
| 独立检测 | `Detect`、`ValidateAnchors`、`AlignNativeLines` | 校验目录、恢复旧文本定位、提取候选并输出可信边界，不执行文件读写 |
| 书库接入 | `internal/book/chapter_index.go`、`internal/book/chapter_parser.go` | 保存索引、读取书库、选择分章模式、组装可阅读章节并统一提供目录和正文查询 |

### 导入阶段

1. `parseOriginal` 按原文件类型选择转换路径。纯文本沿用复制流程；支持的电子书格式进入 `readNativeSource`；远程转换格式取得电子书后复用同一入口。
2. 格式适配器先收集明确的原生目录链接，再按阅读顺序提取正文。渲染到目录目标时记录当前行号；同一正文文件可包含多个目录位置。
3. `textBuilder` 统一处理可见文字、行内空白和段落边界。文档树解析失败时改用流式解析；只有可靠定位的目录才进入结果，正文仍然保留。
4. 构建完成后移除末尾留白，整理同位置的目录条目，标记直接指向正文的 `KeepLine`。单个文件结束时即丢弃无正文目标，避免锚点漂移到下一文件。
5. `writeNativeSource` 校验目录，以正文指纹保存版本化索引，再写出转换文本，由导入流程完成正文提交。没有可用目录时不创建索引，后续阅读使用文本检测。

### 阅读阶段

1. `readBookChapters` 扫描转换文本，保留空行、缩进和物理行号。扫描失败直接返回错误，不使用截断正文继续分章。
2. 按段落数及自定义正则模式直接使用用户配置。默认智能模式先通过 `nativeBookChapters` 查询正文指纹对应的索引，并验证版本、指纹、行号及标题。
3. 索引不可用时，根据书库元数据查找原文件。新解码正文与当前正文相同则复用原生位置；旧转换文本分行不同则按独立标题或已定位的正文首段顺序对齐，任一位置不能恢复便整体回退。正文锚点不会拿书末目录里的同名章名替代。
4. `Detect` 接受有效的完整原生目录时直接返回。没有可靠目录时进行整行评分和全书上下文判断；目录只有正文入口或卷级条目时，补充文本识别的章级边界。
5. `parseChapterLines` 将边界转换为可阅读章节：先结束上一章，再设置新章名；`KeepLine` 保留完整首段，`Body` 保留明确拆出的同行正文，其余未确认行原样归入当前正文。
6. 提交章节时统一忽略无正文的空标题，按章名及正文摘要去重，为同名不同正文生成唯一章名。目录查询和内容查询共用解析结果，避免章名存在却无法定位正文。

### 失效与兼容规则

- 索引绑定解码后正文，不绑定书名。改名或资源包迁移不会单独导致失效；空行、缩进或其他正文变化会改变指纹。
- 恢复旧目录只读取原文件并生成索引，不自动重写旧转换文本。阅读时索引保存失败仍可使用本次内存定位；导入时索引保存失败则返回转换错误。
- 不可靠目录恢复结果以正文指纹和原文件状态作有限缓存，减少反复解压；原文件大小或修改时间变化后允许重新恢复。
- 锚点行号从零开始，包含空行；编号解析结果用于辅助评分，不作为章节在文本中的位置。
- 普通枚举增加上下文复核，避免列表项被切成空章节；真正的短章不要求达到固定正文长度。

## 调用示例

```go
result := chapterdetect.Detect(physicalLines, nativeAnchors)
for _, boundary := range result.Boundaries {
    // boundary.Line: 原始物理行号（从 0 开始）
    // boundary.Title: 标题
    // boundary.Body: 同一行中有明确分隔符时保留的正文
    // boundary.KeepLine: 原生目录直接指向正文时，保留该行
}
```

## 判断流程

1. 正则只提取候选。使用 Unicode 字符数、句末标点、逗号密度和明确的正文引用特征评分；80、120 字是降权起点，长度本身不构成绝对否决。
2. 统计整本书的标题样式和标题长度，结合相邻编号增加可信度。允许缺章、序号重复、分卷重置；强格式标题与无编号前后记分开处理。
3. 检测前保留物理空行、缩进和行号。空行与独占一行提供辅助证据，短章不会因为正文少而被拒绝；连续的普通编号列表不作为章节。
4. 拒绝的候选没有删除动作，调用方应原样加入当前正文。只有标题后出现制表符或多个空格，且后续明显是正文时，才生成 `Boundary.Body`。
5. 验证通过的原生目录位置优先。只有 Start 或卷级目录时继续补充章级判断；无法定位或失效的目录回退到文本检测。

`Result.Candidates` 保留分数和证据原因，可用于调试或后续手动纠错。纯 TXT 中缺乏格式且语义歧义的短句无法保证完全准确。

评分分两轮：第一轮判断前缀、长度、标点、正文引用及留白，仅将相对可靠的候选纳入风格统计；第二轮结合标题长度中位数、主流样式、相邻编号及局部正文形态复核。编号连续只加分，编号不连续不会直接否决，兼容缺章和分卷重置。

`Reasons` 中的英文字符串是稳定的内部原因标识，便于测试和诊断；其含义由对应判断分支的中文注释解释，不直接作为读者界面文案。

## 原生目录与存储适配

- `source/epub.go`：按 OPF spine 阅读顺序提取正文，支持 EPUB 3 nav、EPUB 2 NCX、嵌套目录、同一 XHTML 内多个 fragment。
- `source/mobi.go`：使用 MOBI HTML 中明确的命名目录和 guide 标记的 UTF-8 filepos 目录。普通正文链接不作为目录；无法可靠映射的二进制 KF8 导航回退到文本检测，不猜测字节位置。
- `internal/book/mobi/kf8_index.go`、`kf8.go`：独立解析 KF8 的主流范围、骨架、分片、二进制目录及导引索引。先严格解压并按字节位置重建各正文文档，再将目录中的分片编号和偏移转换为不可见标记；损坏、越界或不支持的交叠结构回退到原有提取路径。
- `source/sections.go`：按原书顺序逐个渲染重建文档，避免多个完整网页拼接后头部书名混入正文。导引指定的目录只隐藏连续的目录标题和链接，保留同文件内随后的真实正文或附录。
- `source/stream.go`：原文件标签不闭合、嵌套过深时使用流式解析，保留正文和可定位的目录；纯文本 MOBI 保留原有物理行。
- 原生目录指向正文段落时，通过 `KeepLine` 保留第一段，标题与正文不会互相吞掉。
- `internal/book/chapter_index.go` 负责磁盘适配：将位置与解码后的文本指纹绑定，保存到 `books/meta-data/chapter-index/<fingerprint>.json`。文件更名、资源导入后仍可使用；正文变化后旧索引失效。
- 对旧转换文件，尝试从 `pure/` 中的原文件恢复并按标题或正文首段顺序精确对齐。不会自动重写旧 TXT；对齐不完整时回退到文本判断。带明确标签且完整列出全部原生标题的旧目录展示行不混入章节正文。
- `internal/book/chapter_parser.go` 继续共用目录和正文解析入口。自定义正则和按段落分章不应用智能过滤，也不强制使用原生目录。

## 验证

```sh
go test ./internal/chapterdetect/... ./internal/book/mobi ./internal/book
```

覆盖长正文误判、Unicode 长度、带标点标题、短章、卷号重置、连续编号列表、明确的同一行边界、EPUB 2/3 目录、MOBI HTML 目录、KF8 索引与分片重建、旧书兼容、索引失效与资源导出导入。可选真实样本《百年孤独》验证二十个章节的正文首段、整本可见文字保留，以及新导入和旧转换文本恢复两条路径。
